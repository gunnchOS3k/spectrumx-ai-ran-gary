# Baseline fairness audit

“Same Slot,” “information_equivalent,” “oracle,” “static” and “no_adaptation” are historical labels. Audit evidence establishes their actual behavior, not fair baseline guarantees. POLICY_INFORMATION_MATRIX.md details per-policy access, used features, actions and allocations.

Original non-static policies receive the full state object. Their read features differ; the linear selector consumes some terms that are constant or dominance-preserving in its argmax. Equal accessible data do not imply equal effective observations or equal optimization work. Revised PolicyObservation materializes only declared fields and raises PermissionError for undeclared access; a focused mobility-access failure confirms that mechanism. Declarations differ across policies. Positive capacities/availability/user counts/priorities remain in shared PolicyActionSpace, so capacity information is accessible outside the observation mask. Declared energy on no_adaptation is unused. There is no equal predictive-estimation fidelity or physical sensing cost.

Positive-capacity placement and category enumeration are selection restrictions, not universally enforced service feasibility. predict_metrics does not reject unavailable networks or overloaded placement; an illustrative absent-TN action still scores positively in both sources. Static freezes a first-slot rule action, including a user-count-dependent allocation, and later availability/user-count changes do not reject it. There is no queue, congestion-dependent throughput, task admission or causal battery constraint. Report its high score as optimistic under incomplete feasibility.

Computational opportunities differ: some policies use seededSLSQP shares, others uniform/priority shares or discrete enumeration. The greedy evaluator invokes the analytical model, and revised version enumerates fidelity too; it is privileged current-state evaluation but no future-time access/horizon guarantee. Controllers mostly ignore previous actions when selecting; cost is nevertheless deducted consistently by the evaluator except no_switch_cost. Equal scored penalties do not mean equal transition-aware selection or measured switching cost. Revised checkpoint actions alter endogenous episode state and incur additional costs, so adaptive-vs-disabled comparisons are whole-policy comparisons.

no_adaptation is cloud fallback: it changes category ifTN unavailable. cloud_only is a different preferred fallback (NTN before generic first category), not the primary reference. Original linear and no_adaptation select the same lowest-alpha path on generated full states; placements differ. An observed procedural/linear difference cannot identify value of twin information alone. Fidelity means service quality factor, not model prediction accuracy. no_edge_observations zeros the truth used for control and scoring in both engines; no_energy_constraint changes a covariate rather than removing depletion; no_continuity_objective changes class but retains the score. Only unchanged-action cost subtraction is a clean narrow accounting probe.

These limitations do not invalidate faithful reporting of the frozen numerical outcomes. They block causal twin-information superiority, equal-compute advantage, true service-feasibility rankings and global optimality claims. A future study needs a new protocol with common truth, explicit restricted observations, feasible actions, budgets and matched computational accounting. Historical result arrays remain intact.
