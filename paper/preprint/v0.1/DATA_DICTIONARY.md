# Data dictionary and numerical limits
Data directories original/revised contain exact source-commit outputs; original_reproduced/revised_reproduced contain retained historical reruns. They are not separate independent studies. Each has train, heldout, domain_shift, ablation and summary JSON. Original/revised are distinct generators; never pool seeds across them.

Family JSON: family/ablation labels; seeds ordered [0..4] or [100..104]; n_episodes_per_seed24; n_slots_per_episode16. policies maps stored policy names to metric summaries and seed_means. Metric summaries contain mean, std, ci95_low/high and n (check raw spelling in supplied JSON); seed_means arrays preserve paired seed order. domain_shift and ablation wrap family objects by intervention name. summary aggregates metadata/hypothesis results, not additional samples. effect_sizes stores pooled-standard-deviation Cohen d versus no_adaptation, not paired d_z. No raw packets, per-slot action trace, measured device or satellite data exists. Raw outputs here means raw retained JSON summaries/seed means.

service_continuity_utility: dimensionless slot score averaged over16slots,24episodes,5seeds. predicted_latency_ms and energy_use_j: analytical/proxy labels, not physical measurements. reliability/continuity/fairness and outage-related metrics follow frozen source. fairness is Jain share index, not per-task service fairness. n_network_switches/n_placement_switches: episode counts; switch_cost: configured episode sum (divide16 for mean slot cost). compute_time_ms: nondeterministic host-process execution timing, not RAN slot latency. Fidelity values in revised are service-level synthetic factors, not twin calibration errors. Power is dimensionless; energy is not a depleted battery.

Independent statistics JSON gives n,mean,sample_sd,ci95,paired_dz,seed_differences; n=5 per comparison. Floating-point scientific parity is exact for preserved reruns and checked anew where reproduction is run; portability outside recorded dependency/runtime is not guaranteed. Timing is validated as finite/nonnegative with matching schema and retained separately. Only exact compute_time_ms branches are excluded from scientific equality. Dictionary keys/array lengths, seed order, versions and all other values remain checked. No timestamp/source/hash fields are silently excluded. Archive hashes cover those bytes too.

Original marginal t4 is rounded2.776; new paired tables use SciPy quantile. SLSQP default tolerances yield small residuals, not exact budget feasibility. The numerical bound and original failed assertion remain supplied.
