# Plain-language research summary
This study checks what a small simulated network controller actually does. Its complex-sounding linear rule usually reduces to choosing edge processing on the available connection with the smallest configured delay multiplier. The procedural twin rule scores worse than a cloud fallback rule in both preserved versions; changing the quality or checkpoint rule also hurts the configured score. Some comparisons cannot tell us whether twin information itself helps because rules receive/use different information and actions are not uniformly checked for feasibility. The allocation optimizer solves a different symmetric objective and mostly returns equal shares. These are reproducible findings about code and assumptions, not satellite measurements, real battery tests or proof that digital twins are ineffective. The public value would be a transparent methodological case study. Human scientific and originality review is still required.
