# Controller, observation and action contracts

Files: src/fair_control/controllers.py, fairness.py, isolation.py; P4 core.py remains unchanged. Model/dynamics/evaluator are separate modules.

All families declare timestamp_s, estimated_paths, task_queue, remaining_energy_j, previous_action and forecasts. Strict nested field validation rejects future_truth/realized_truth/undeclared payloads, duplicate IDs, nonfinite values and excessive input size (64 queued task estimates,4 current paths,2 forecast steps). Whitelisting deep freezes selected fields and records accessed names; this is an audit API, not a malicious-Python sandbox. Honest forecast provenance still needs an approved causal estimator; renaming actual future values “forecasts” cannot be detected by field names alone. No future truth is present in bundled requests.

Hardware limits/Model costs are identical immutable Opportunity declarations; validate_opportunities rejects differing memory/resource/cost/compute identities. validate_pair checks identical accessible fields, evaluation/wall limits and equal exogenous timestamp/path/forecast bytes. Own causal task/battery/previous state may differ after policy actions. matched_decisions enforces these declarations and passes shared hardware/model to both eligible candidates. Candidate catalogs use public estimates only; true validation occurs solely after selection. Catalog/resource/cost identity does not promise identical action rankings or resource use. Every controller sees the same options for identical own state, except explicitly labeled fixed-target secondary baseline restricts fidelity and is not action-equivalent.

Catalog: one network and one placement per step, available estimated paths × local/edge/cloud × equal/demand-priority/deadline weights × target/degraded; explicit defer. Memory admission is earliest deadline then task ID, with unallocated tasks retained as failures/incomplete in the endpoint. All candidates obey estimated global/placement/resource/energy/cost bounds; execution may reject stale estimates under true state. Exactly equal estimated feasibility does not promise true availability. Lexicographic placement/network/fidelity and canonical allocation digest stabilize ties, including defer where ordering places it. This ordering is an implementation default, pending science review.

Prediction uses estimated data/CPU/latency/remaining work/deadline/age/quality/battery and migration progress reset. It assumes supported backend output/durability will be correct; the post-execution oracle checks actual bytes independently. No predictive model is fitted or calibrated. Current control interval is1s, a provisional constructed default; variable-duration Environment frames exist but the candidate prediction interface must be fixed/revised before a different control period campaign. MPC stops at available horizon, records BOUNDED_SEARCH_COMPLETE; this is finite approximate search completion, not a certificate of global optimality. Missing/invalid input raises a contract error; model arithmetic/failure produces MODEL_FAILURE and defer. Limit exhaustion produces BUDGET_EXCEEDED and defer, retaining actual calls. No privileged oracle is implemented.

ComputeLedger starts before catalog construction after contract validation and checks time around catalog/prediction calls. Each predict call is charged before execution; attempted failed calls count. Max512 evaluations and100ms proposed cooperative wall opportunity are equal for the primary pair; actual used calls/time differ and are recorded. Fast simple rules use0 model calls, not512 fake calls. Input contract validation and process startup are separate overhead; this is not full hard real-time accounting. Optional decide_isolated enforces a hard child-process envelope at the same startup allowance1s + inner100ms limit for all families, records outer overhead, and kills/reaps timeout child before returning defer. Tests exercise real child success, failure and hang timeout. This wrapper is operational but not used by the single in-process engineering-run fixture; it must be selected identically for a future campaign. No hostile-code containment, descendant-process tree protection or deployment deadline guarantee is claimed.

Statuses/time/source/catalog/observation hashes and consumed fields are preserved. Timing is nondeterministic provenance separated from the deterministic outcome payload; logs retain it and do not claim full bit equality including wall clocks. No policy has privileged actual-future access; the model is Python-contract controlled rather than adversarial security isolated.
